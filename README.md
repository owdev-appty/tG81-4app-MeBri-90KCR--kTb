# 衝動タイマー

衝動的な間食・過食が来た瞬間に割り込み、ピークが過ぎるのを待つためのPWA。

- 素の HTML / CSS / JavaScript（ビルド不要）
- データは `localStorage` のみ。外部通信なし
- GitHub Pages で静的ホスティング

## 使い方（iPhone）

1. Safari で公開URLを開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンからワンタップで起動

## 画面

| 画面 | 内容 |
| --- | --- |
| ホーム | 「食べたい」ボタン（下部に小さく「記録」「設定」） |
| 気分選択 | Drunk🍺 10分 / Cannot stop eating🤮 15分 / Stress😤 10分 / なんとなく 10分 |
| タイマー | カウントダウン、「🎵 隣のショートカットで好きな曲を」、目立たない「今すぐやめる」 |
| 終了 | 振動 →「まだ食べたい？」いいえ＝我慢できた+1 / はい＝代替スナックを1つ提示 |
| 記録 | 今週・先週・累計の「我慢できた / 挑戦した」を数字のみ表示 |
| 設定 | 気分ラベル・タイマー分数・代替スナック・深夜モード時間帯（初期値 22時〜翌5時） |

## カウントの定義

- 挑戦した回数：タイマーを起動した回数（「今すぐやめる」で中断した場合も含む）
- 我慢できた回数：終了画面で「いいえ」を選んだ回数

## 補足

- iOS Safari は Vibration API（`navigator.vibrate`）に非対応のため、iPhone では終了時に振動しません（Android では振動します）。
- タイマー中は Screen Wake Lock で画面の自動消灯を抑止します（対応環境のみ）。
- アプリを閉じてもタイマー終了時刻は保存され、再度開くと残り時間から再開、または終了画面を表示します。

## ファイル構成

```
index.html            画面
style.css             スタイル（深夜モード含む）
app.js                ロジック
sw.js                 Service Worker（オフライン起動用）
manifest.json         PWA マニフェスト
icon-512.png          アプリアイコン 512x512
apple-touch-icon.png  iOS ホーム画面用アイコン 512x512
```
